# ai-secretary

Капстоун №21, KSE Agentic AI Summer School 2026. Шар відповіді над документообігом
військової частини. Огляд проєкту для людей — `README.md`.

## Правило даних — жорстке

**У git не їде жодна бойова, тактична або персональна інформація.**

Це не рекомендація. Репозиторій побачить університет, а джерело документів —
військова частина.

- Реальні документи замовника — **тільки локально**, у `data-private/`, яка в `.gitignore`
- У репо — синтетика й шаблони, нічого більше
- Синтетичні зразки документів живуть у `eval/synthetic/`
- `knowledge-base/` — тільки **публічні** нормативні акти (закони, накази МО у
  відкритому доступі). Внутрішні документи частини туди не кладемо
- Сумнів, чи можна файл у git → **не кладемо**, питаємо Дениса

Побачив у діффі реальний документ — зупиняєшся і кажеш, не комітиш.

## Мова

Код, назви папок і файлів — англійською. Коментарі, документація, комміти — українською.

Одне поняття — одна назва. Термін беремо зі словника нижче й не вигадуємо синонімів.

| Термін | Що означає |
|---|---|
| **Шар відповіді** | Те, що ми будуємо. Не документообіг — він у замовника є. Надбудова над документами, які вже ходять |
| **Дві дороги відповіді** | Дорога А: факти → цифра. Дорога Б: питання → цитата з норм-акта. Спільна база документів, різні механізми |
| **Маршрутизація** | Крок, який вирішує, якою з двох доріг іде конкретне питання |
| **Склад відповіді** | Чотири обов'язкові елементи біля цифри: дата зрізу, знаменник, кількість непідтверджених, посилання на документ-джерело |
| **Наскрізна нитка** | Один документ проходить весь ланцюг від входу до відповіді. Не «є частини» |
| **Чернетка** | Запис із хоч одним непевним полем. У підрахунки не входить, доки людина не підтвердить |
| **Відмова** | Система каже «не знайшла» замість того, щоб вигадати. Відмова краща за вигадану цифру |
| **Власник** | Одне ім'я, яке відповідає «у якому стані» і «коли запрацює» |

## Структура

Папка верхнього рівня = ділянка з одним власником. У корінь код не кладемо.

| Папка | Власник | Що там |
|---|---|---|
| `pipeline/` | Аня | OCR → класифікація → витяг полів → нормалізація |
| `db/` | Андрій | MinIO (об'єкти) + Postgres (факти) |
| `knowledge-base/` | Коля | публічні норм-акти для дороги Б |
| `eval/` | — | синтетичний корпус + еталонні відповіді |
| `docs/` | Денис | мапа доріг, рішення, схеми |

## Рішення, які не переобговорюємо

Прийняті 03.08.2026 з альтернативами. Хочеш змінити — спершу підніми перед Денисом.

- **Обидві дороги паралельно**, на спільній базі документів
- **Один тип документа наскрізь** до другого демо, решта — після
- **Тип — рапорт на відпустку**: є в корпусі в кількох варіантах написання ·
  дає цифру, яку можна порахувати · до нього існує публічний норм-акт
- **Вікно чату — Gradio або Streamlit**, один файл. Не вебзастосунок:
  у команді немає фронтендера, виконавців троє
- **Модель — MamayLM**

## Межі агента

- Пишу у файли тільки на «пиши / ок». Структурні зміни — спершу план
- Не видаляю — переношу в `_archive/`
- Важке (PDF, відео, презентації) у git не тягну
- Повідомлення команді в Telegram і сабміти у форми KSE — **шле Денис сам**.
  Агент готує чернетку
