# Генератор синтетичних документів

Робить набір документів для перевірки пайплайна: відпускні квитки і
посвідчення про відрядження. Замовник реальних документів не дає — цей
набір їх замінює.

Готові 30 документів лежать у `data/eval/samples/`. Тут — те, що їх зробило.

## Запуск

    pip install -r requirements.txt
    brew install --cask libreoffice
    brew install poppler
    python generate.py

На виході — папка `output/`: на кожен документ `.docx`, `.json` (еталонні
значення полів), `.pdf`, `.png` лице і зворот. Плюс `ЕТАЛОН.csv` і
`КАЛЕНДАР.csv`.

`seed: 2026` у `налаштування.yaml` — той самий номер завжди дає той самий
набір.

Шляхи до LibreOffice і poppler зашиті під macOS з Homebrew
(`/opt/homebrew/bin/`), з відкатом на `PATH`.

## Дані вигадані. Це перевіряється, а не заявляється

`data/unit_roster.csv` — 300 людей, 37 колонок, серед них податковий номер,
серія і номер паспорта, дата народження. Це згенерований набір, не реєстр
живих людей. Докази:

- **Контрольну суму податкового номера проходять 24 з 300.** У реальному
  реєстрі її проходять усі 300: цифри тут випадкові, і 24 збіги — рівно те,
  що дає випадковість
- Перші п'ять цифр податкового номера мають кодувати дату народження —
  **не збігаються в жодному з 300 рядків**
- 128 із 149 серій паспорта не існує; у шести рядках стоїть російська «И»
- Код оператора, який існує в українській нумерації, мають 23 телефони з 300
- Ім'я збігається з коренем по батькові: Ватаманюк Аарон Ааронович
- Місця народження зібрані випадково: «село Чугуїв», «село Дрогобич»

Номер військової частини в реєстрі відсутній. Він задається в
`налаштування.yaml` одним умовним значенням `А0000`. Підписант документів і
організації, куди відряджають, — теж умовні.

## Що всередині

| Файл | Що це |
|---|---|
| `generate.py` | генератор |
| `налаштування.yaml` | словники, seed, умовний номер частини |
| `prepare_templates.py` | робить бланки з мітками з порожніх бланків |
| `data/unit_roster.csv` | реєстр особового складу, синтетичний |
| `templates/` | два порожні бланки і дві версії з мітками `{{ПОЛЕ}}` |
| `ТЗ.md` | постановка задачі |
| `ТЕСТОВІ-ПИТАННЯ.md` | питання для перевірки набору |
| `unit_roster_structure.html` | всі 37 колонок реєстру з поясненням |
| `unit_roster_critique.html` | розбір якості реєстру: що в ньому не тримається |
| `reference/synthetic_docs_stress_test.md` | 22 вигадані документи для стрес-тесту |

Бланки — Додаток 30 і Додаток 28 до Інструкції з діловодства у ЗСУ,
публічні форми. Генератор тільки вписує значення в порожні місця.
