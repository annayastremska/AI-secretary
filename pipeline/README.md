# pipeline — розбір документа

Власник: Аня.

Ланцюг: **фото/скан → OCR → класифікація типу → витяг полів → нормалізація → факт у базі**.

До другого демо ланцюг проходить наскрізь один тип документа — рапорт на відпустку.

## Що тут лежить

Поки порожньо. Код з'являється тут.

## Правило даних

Реальні документи замовника сюди **не кладемо** — ні для тестів, ні тимчасово.
Зразки для розробки беремо з `eval/synthetic/`.

## Чернетка vs підтверджений факт

Запис, у якому хоч одне поле розібралось непевно, — **чернетка**. У підрахунки
не входить, доки людина не підтвердить. Пайплайн мусить відрізняти одне від
одного і віддавати в базу разом із позначкою.
