# normalization

Постобробка сирих значень з extraction/ перед записом у БД:
- дати → ISO (`YYYY-MM-DD`);
- ПІБ → називний відмінок (морфологічний аналізатор uk, не LLM);
- категоріальні поля → звірка з `dictionaries/*.yaml` (canonical code чи
  «термін не розпізнано»);
- object_ref поля → резолюція в реєстр об'єктів (штатна книжка тощо).
