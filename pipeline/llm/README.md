# llm

Обгортка над `llama-cpp-python` (`client.py`). Два режими, обидва
grammar-constrained — модель фізично не може вийти за межі дозволеного:

- `choose(prompt, choices)` — вибір рівно одного варіанта (визначення
  шаблону/домену). `"unknown"` завжди серед варіантів, інакше модель була б
  змушена вибрати щось із закритого списку навіть коли жоден не підходить.
- `extract_batch(field_defs, context_text, json_schema)` — група полів за
  один виклик; JSON Schema будується в `pipeline/extraction/schema_grammar.py`
  з самої схеми бланка й довідників, тому категоріальне поле не може
  отримати неіснуючий код.

Grammar гарантує **форму** відповіді, не її правдивість.

`llama_cpp` імпортується ліниво: решта пайплайна працює на машині без
моделі — детермінований прохід дає результат, прогалини чесно позначені.
