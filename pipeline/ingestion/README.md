# ingestion

Точка входу: файл → `(text, blocks)` у єдиному форматі, незалежно від джерела.

- `.docx` — пряма екстракція (параграфи + клітинки таблиць + header/footer),
  без OCR. Об'єднані клітинки дедуплікуються: `python-docx` повертає їх
  окремо для кожної колонки сітки.
- зображення — через `ocr_fn` (див. `pipeline/ocr/`), далі впорядкування
  блоків за геометрією `bbox`, а не за порядком, у якому їх видала модель.
- `file_sha256` — ідентичність документа за вмістом; основа дедуплікації
  (той самий документ, завантажений двічі, не має дати два факти).
