# ingestion

Точка входу: файл → `(text, blocks)` у єдиному форматі, незалежно від джерела.

- `.docx` — пряма екстракція (параграфи + клітинки таблиць + header/footer),
  без OCR. Об'єднані клітинки дедуплікуються: `python-docx` повертає їх
  окремо для кожної колонки сітки.
- `.pdf` — два шляхи залежно від вмісту (потрібен `pymupdf`):
  є текстовий шар → `page.get_text("blocks")` віддає блоки **разом з
  координатами**, тому PDF отримує таку саму геометричну обробку, як OCR,
  але без OCR; тексту фактично немає (скан у PDF-обгортці) → сторінки
  рендеряться в зображення й ідуть через `ocr_fn`. Блоки сортуються
  всередині кожної сторінки окремо, бо y-координати на кожній сторінці
  починаються з нуля — спільне сортування перемішало б сторінки.
- зображення — через `ocr_fn` (див. `pipeline/ocr/`), далі впорядкування
  блоків за геометрією `bbox`, а не за порядком, у якому їх видала модель.

Змішані PDF (частина сторінок з текстом, частина скановані) окремо не
обробляються: рішення приймається один раз на весь документ за середньою
кількістю символів на сторінку.
- `file_sha256` — ідентичність документа за вмістом; основа дедуплікації
  (той самий документ, завантажений двічі, не має дати два факти).
