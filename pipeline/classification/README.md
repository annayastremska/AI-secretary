# classification

Визначення ДОМЕНУ документа (leave / deployment / equipment / staffing) за
ключовими фразами з `dictionaries/domain_keyphrases.yaml`: заголовок ×3,
фрази тіла ×1, плюс LLM-фолбек, коли правила не дали збігу.

Вибір конкретної СХЕМИ бланка — не тут, а в `pipeline/identification.py`
(схема прив'язана до `template`, а один домен містить багато різних
бланків). Домен звідси використовується як грубший сигнал: він дає
контекст для черги `unresolved`, коли жоден шаблон не впізнано.
