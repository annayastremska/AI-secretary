# knowledge-base — джерела для дороги Б

Власник: Коля.

Дорога Б відповідає на процедурні питання цитатою з нормативного тексту:
«Яка процедура подання заяви на відпустку?» → цитата + посилання на джерело.

## Що тут лежить

Поки порожньо — самі тексти лежать поки в `data/eval/samples/normative/`
(сім публічних актів: закони про військовий обов'язок і соціальний захист,
Положення про відпустки, інструкції з діловодства). Вони там тому, що
`.gitignore` пускає файли документів **лише** в `data/eval/`; дублювати їх сюди
не треба — краще посилатися.

## Тільки публічні документи

Сюди йдуть **виключно нормативні акти у відкритому доступі** — закони, постанови,
накази Міністерства оборони, опубліковані на офіційних сайтах.

Внутрішні документи частини — накази по частині, розпорядження, інструкції для
службового користування — **не кладемо**, навіть якщо вони описують ту саму
процедуру.

Кожне джерело супроводжується посиланням на офіційну публікацію. Немає посилання —
немає джерела.

## Відмова замість вигадки

Якщо в базі знань немає відповіді на питання, система каже «не знайшла».
Переказувати норму по пам'яті моделі не можна: цитата без джерела гірша
за відмову.
