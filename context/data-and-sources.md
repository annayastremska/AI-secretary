# Дані та джерела документів

## Типи документів

Приклади з опису проєкту: люди (особовий склад), техніка/транспорт, місії.

**Перелік НЕ вичерпний — потребує уточнення з військовими під час інтерв'ю.**

## Формат зберігання

- Частина документів — паперова, зберігається як фото сканів/фотографій.
- Частина — цифрова, через системи на кшталт Армія+, АСКОД та ін.

## Конфіденційність даних

Реальні документи вкрай конфіденційні — настільки, що модель НЕ можна тренувати навіть на них.

## Стратегія даних для розробки

- Порожні шаблони документів (частина буде надана клієнтом, частина — знайдена онлайн; деталі уточнюються).
- Синтетичні дані, згенеровані на основі шаблонів, де це потрібно.

## Диджиталізація паперових документів

Робимо самі (не клієнт). Конкретний інструмент/метод не обрано — варіанти в open-questions.md.

## Інтеграція з Армія+/АСКОД

Підтверджено дослідженням (липень 2026): публічного API не існує для жодної із систем — перевірено офіційний маркетплейс держпослуг і сайти вендорів, документації розробника не знайдено. Як саме поповнюватиметься наша база даних без прямого доступу — відкрите питання, що потребує відповіді від військових (див. open-questions.md). Деталі й джерела — research-insights.md.
