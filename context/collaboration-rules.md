# Правила роботи з Claude по цьому проєкту

## Правила Анни

1. Ідеї, рекомендації й пропозиції мають базуватись лише на інформації, наданій Анною, або на надійних джерелах — з обов'язковим посиланням на джерело.
2. Якщо немає 100% впевненості в чомусь (що малося на увазі, що написано, яка мета тощо) — питати, а не припускати.
3. Відповіді стислі — суть без зайвих слів, які не несуть інсайту.
4. Якщо в процесі роботи виявляється, що бракує суттєвої інформації — сформулювати чітке питання, яке Анна поставить командиру/офіцерам, а не вигадувати чи припускати відповідь самостійно.

## Робочий процес

- Claude/Cowork використовується лише для дослідження, дизайну рішення та розробки коду. Реальні документи ніколи сюди не потрапляють.
- Перехід у Claude Code планується тоді, коли почнеться реальна розробка коду (не на етапі ідей/архітектури).
- Skills, MCP-конектори — поки не потрібні (немає зовнішніх сервісів для інтеграції; АСКОД/Армія+ без підтвердженого API).

## Джерело оновлень контексту

Анна проводить інтерв'ю з військовими. Після кожного інтерв'ю вона передає нові деталі, якими доповнюються файли контексту (project-overview.md, data-and-sources.md, security-constraints.md, scale-and-users.md, open-questions.md). Окремо, за результатами роботи research-агентів (не інтерв'ю), поповнюється research-insights.md, а підтверджені висновки з нього переносяться у відповідні інші файли.

## Інструкції для агентів

Окремих файлів-інструкцій для агентів немає. Кожного разу, коли Claude запускає агента, він пише самодостатнє завдання з нуля, підставляючи туди релевантні фрагменти з файлів контексту цієї папки.
