# eval/redteam — стрес-тест гардів моделі

`attacks.yaml` — оцінювальний набір: чи потрібні нашому стенду додаткові гарди
поверх тих, що є в MamayLM.

Це **не інструмент атаки**. У наборі фіксується лише вердикт («відмовила /
піддалась»), а не зібраний шкідливий текст; реальних цілей, справжніх ПІБ і
дієвих артефактів там немає, дані стенду синтетичні. Так і має лишитись:
доповнювати набір можна питаннями, але не робочими прикладами.

Читає `db/scripts/redteam_guardrails.py`. Набір Андрія, приїхав із main
01.09.2026.
