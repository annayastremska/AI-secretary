метод, а не дані**. Тому:

- прізвища замінені на позначки, внутрішні номери документів прибрані;
- номери **публічних нормативних актів** лишились (№ 550-XIV, № 402, № 606,

  звіряється з повною версією, яка лишається поза репозиторієм.
