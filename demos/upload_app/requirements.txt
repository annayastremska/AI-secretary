#
# Extra [local] у semantic-router тягне СВІЙ llama-cpp-python -- звичайне
# колесо з PyPI, зібране БЕЗ CUDA. На машині, де вже стояла CUDA-збірка, pip
# її тихо замінює: `llama_supports_gpu_offload()` стає False, і виклик моделі
# їде 43 с замість 0.21 с. Нічого не падає, у логах чисто -- просто в 200
# разів повільніше. Саме так ми й втратили прискорення, не помітивши.
#
# Тому на GPU-машині ПІСЛЯ цього файла обов'язковий крок:
#
#   pip install --force-reinstall --no-cache-dir llama-cpp-python==0.3.16 \
#       --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cu124
#
# Перевірка, що спрацювало (одна команда, не «на око»):
#
#   python -c "import sys;sys.path.insert(0,'.');\
#   from pipeline.llm.cuda_preload import preload;preload();\
#   from llama_cpp import llama_cpp as c;print(c.llama_supports_gpu_offload())"
#
# Мусить бути True. На ноуті без CUDA -- False, і це нормально.
