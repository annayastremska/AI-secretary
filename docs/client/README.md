# docs/client — що ми знаємо від замовника

Тут лежать зведення того, що замовник просить і чого не просить. Не листування,
не записи розмов, не сирі матеріали.

| Файл | Що це |
|---|---|
| `customer-request.md` | Запит замовника станом на 01.08.2026: користувач, етапність, відкриті питання |

## Правило цієї папки

Дослівних формулювань замовника, імен людей, назв підрозділу і назв внутрішніх
систем тут немає — свідомо. Робочі матеріали розмов лишаються локально, у репо
йде тільки зведення.

Кладеш сюди файл — спершу перечитай його на ці чотири ознаки.
