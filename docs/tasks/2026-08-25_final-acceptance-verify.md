## 1. П7 — валідатор SQL (22 атаки, нічого не виконувалось)

Відхилено правильно: два statement через `;`, DML прямо, DML у підзапиті,
`--`, `/* */`, CTE з DELETE, `pg_shadow`, `information_schema`, `pg_sleep`,
`SELECT INTO`, `facts` без слова confirmed.

**ПРОБИТО рейку 3 («фільтр підтвердженості перевіряє КОД»)** — перевірка це
підрядок `"confirmed" not in sql.lower()`. Проходять:

| запит | наслідок |
|---|---|
| `SELECT count(*) AS confirmed FROM facts` | рахує ВСІ факти — чернетки разом із фактами |
| `... WHERE f.status = 'unconfirmed'` | «unconfirmed» містить «confirmed» |
| `... WHERE f.value LIKE '%confirmed%'` | статус не фільтрується |
| `... WHERE f.status <> 'confirmed'` | лише НЕпідтверджені |

Ще: `LIMIT 200` не примусовий (LIMIT у підзапиті приймається за зовнішній);
`SELECT * FROM "documents"` хибно відхиляється як «запит без таблиці».
