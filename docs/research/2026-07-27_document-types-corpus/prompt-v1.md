3. «Не знайдено» — валідний і корисний результат. Не вигадувати, не натягувати. НЕ ВИГАДУВАТИ перелік граф — тільки дослівно з відкритого джерела.

5. Обов'язково фіксувати ФОРМАТ: HTML-текст / текстовий PDF / СКАН-ОБРАЗ PDF (без текстового шару) / DOC / XLS. Скани позначати окремо.
6. Писати стисло, без води. Вихід — дані для таблиці, не звіт для читання.
7. Робочий бюджет: 12–20 WebSearch/WebFetch викликів. Не менше 10 реально відкритих сторінок.
