### Текст промта (прогін 1)

Проведи research (веб-пошук обовʼязковий, не покладайся лише на памʼять) і відбери
ШОРТЛІСТ (3-5 моделей) embedding-моделей для конкретного кейсу. Відповідь пиши
українською.

**Контекст.** Розробляється демо-версія системи обробки документів для військового
підрозділу України (проєкт milidoc). Дві підсистеми: (1) фактологічний конвеєр —
документи → структуровані факти в PostgreSQL → відповіді через фіксовані SQL-шаблони,
embeddings НЕ потрібні; (2) нормативна підсистема («second brain») — процедурні
документи (інструкції, накази, положення) як текст + YAML-метадані, пошук спочатку
через PostgreSQL FTS, а pgvector підключається ТІЛЬКИ якщо FTS виявиться недостатнім
на реальному корпусі. Саме для другого сценарію потрібна embedding-модель.

**Жорсткі вимоги (не обговорюються).** Повністю self-hosted, без інтернету, без
хмарних API (замовник — військові). HuggingFace / sentence-transformers / ONNX — ОК;
OpenAI / Cohere / будь-який embeddings-API — НІ, навіть як опція. Прод — один сервер
з однією відеокартою. Дев-машина зараз без GPU (тестуємо на CPU), тож модель має бути
реалістичною і для CPU-інференсу. Генеративна LLM (MamayLM-Gemma-3-12B через Ollama) —
decoder-only, без embedding-режиму; embedding-модель завжди окрема.

**Що вже розглядали (стартова точка, НЕ обмеження пошуку).** BGE-M3 (BAAI, MIT, 100+
мов, 8192 токенів, dense+sparse+multi-vector). Qwen3-Embedding (Apache 2.0). Референс:
робота «An End-to-End Ukrainian RAG for Local Deployment» (arxiv 2604.22095, UNLP 2026,
2-ге місце) використовує BGE-M3 + BM25 + RRF + bge-reranker-v2-m3 + MamayLM-12B (LoRA).
Прочитай її та суміжну «Toward Agentic RAG for Ukrainian» (arxiv 2604.14896), витягни
ablation-таблиці з метриками retrieval на українській.

Не обмежуйся двома названими. Пошукай інші мультимовні (multilingual-e5, GTE-multilingual-base,
LaBSE, jina-embeddings-v3, snowflake-arctic-embed-m-v2.0, granite-embedding-multilingual,
EmbeddingGemma, model2vec) і окремо — українськомовні fine-tune (lang-uk, ukr-models,
awesome-ukrainian-nlp).

**Три критерії (у порядку значущості).** (1) Розмір/footprint — вага на диску, RAM,
швидкість. (2) Якість саме на українській — НЕ загальний MTEB average; шукай UA-специфічні
бенчмарки, обсяг укр. даних у тренуванні, приклади реального використання. Немає доказів —
так і напиши. (3) Інтеграція з pgvector — розмірність вектора, стандартність виводу,
простота запуску, ліцензія (MIT/Apache ідеально; окремо познач CC-BY-NC та інші
обмежувальні).

**Формат.** (1) Шортліст 3-5 моделей, одне речення чому кожна. (2) Таблиця: Модель |
Розмір | Розмірність вектора | Контекст | Ліцензія | Якість на українській (конкретні
докази) | Легкість інтеграції з pgvector | Плюси | Мінуси. (3) Фінальна рекомендація
з trade-off-ами. Кожне число — з посиланням на джерело. Наприкінці — список джерел.
