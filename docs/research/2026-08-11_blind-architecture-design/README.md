## Метод

Агент, який бачить наше рішення, буде його доводити. Тому в бриф свідомо не
потрапили: наш поділ питань на типи, обрана бібліотека вікна чату, обрана
embedding-модель, порядок «спочатку повнотекстовий пошук, вектор запасним».
Перелік прихованого — таблицею в `brief-blind.md`.

**Критерії зафіксовані до запуску:** сильне підтвердження — та сама структура і ті
самі компоненти; середнє — та сама структура, інші компоненти; розбіжність — інша
структура, і це найцінніший результат. Вийшло сильне підтвердження по структурі.

Той самий прийом застосований при виборі embedding-моделі —
`docs/research/2026-08-08_embedding-model-selection/`.
