# Моделі: OpenRouter ↔ локальний запуск

Перелік vision-моделей, які є **і на OpenRouter, і з відкритими вагами** (тобто той
самий чекпойнт можна поставити локально). Витягнуто з `openrouter.ai/api/v1/models`
**27.07.2026**: 341 модель усього, 183 з них приймають зображення.

Твоє залізо: **Apple M1, 8 ГБ RAM**. Це головне обмеження — під MLX/Ollama реально
доступно ~5.5–6 ГБ, решту тримає система.

## Чого на OpenRouter немає взагалі — тільки локально

Спеціалізовані OCR-моделі як API не віддаються. Якщо VLM-и на рукописі провалються,
другий трек — саме вони (окремий скрипт, не цей):

| Модель | Що це | На M1 8 ГБ |
|---|---|---|
| **PaddleOCR** (з ukr) | класичний OCR-конвеєр детекція+розпізнавання | ✅ легко, CPU |
| **Tesseract** `ukr` | базова лінія 20-річної давнини | ✅ але на рукописі майже нуль |
| **Surya** | детекція+розпізнавання, 90+ мов | ✅ ~2 ГБ |
| **TrOCR** (handwritten) | заточена саме під рукопис, але тренована на латиниці | ✅ потребує дотренування на кирилиці |
| **dots.ocr / olmOCR / Nanonets-OCR** | VLM-и суто під документи, 1–7B | ⚠️ 3–5 ГБ, влізуть |

## Що з цього стоїть у `models.txt` за замовчуванням
