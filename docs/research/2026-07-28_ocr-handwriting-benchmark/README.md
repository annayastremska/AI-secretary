# Чи читає модель рукописний бланк — бенчмарк 27–31.07.2026

Gate 0 проєкту: перш ніж будувати конвеєр, треба було знати, чи взагалі якась
модель читає рукописно заповнений документ.

**Вердикт: читає, але сама не гарантує результат.** Найкраща з семи моделей —
87% по всій базі й **59% на найважчих полях** (підпис, паспорт, ІПН, дата видачі).
Тому в архітектурі стоїть підтвердження людиною, а не автоприйом.

Головний файл — `handwriting-recognition-case-study.html`. Там усі цифри,
порівняння семи моделей і те, що не спрацювало.

| Файл | Що це |
|---|---|
| `handwriting-recognition-case-study.html` | кейс: метрики, порівняння 7 моделей, макет бланку замість скана |
| `run_benchmark.py` | стенд: PDF → PNG → кожна модель → зведена таблиця «поле × модель» |
| `fields.yaml` | схема 42 полів бланку, 6 секцій |
| `prompt.md` | шаблон промта · `prompt-as-sent.md` — як його склали й відправили |
| `models.txt` · `models-notes.md` | які моделі гнали; що з них ставиться локально і чи влізе у 8 ГБ |

## Три результати, які варто знати до того, як щось будувати

- **Голосування кількома моделями не працює.** На найважчих полях більшість голосів
  дала 5.7% — гірше за одну модель окремо. Хоч одна з семи вгадувала правильно у 80%
  випадків, але вибрати, яка саме, без людини неможливо
- **Класичний OCR без «зору» моделі дає на рукописі нуль.** Перевірено окремо
- **Точність рахували трьома шарами**, і це важливо для чесності цифри: усі 408
  клітинок бази · 338 «консенсусних» (моделі згодні між собою, людина не звіряла) ·
  70 найважчих, звірених зі сканом вручну. Тільки третій шар — справжня точність

## Чого тут немає і не буде

Бенчмарк ішов на **реальних заявах реальних людей**. У репо не їдуть і не поїдуть:
самі документи, скани, еталонні відповіді, вивід моделей і зведена таблиця
`ПОРІВНЯННЯ.md` — у кожній її клітинці паспортні дані, ІПН, телефони, склад родин.
Усе це лишається локально.

Наслідок: `run_benchmark.py` у свіжому клоні не має на чому працювати. Він це
розуміє — без папки `documents/` каже, чого бракує, а не падає трейсбеком. Щоб
відтворити прогін, треба покласти свої документи і свій ключ OpenRouter у `.env`.

Кейс відкривається в браузері з інтернетом — стилі тягнуться з CDN.
