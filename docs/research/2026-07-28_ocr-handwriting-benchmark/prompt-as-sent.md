Це сторінка рукописно заповненого документа українською мовою — бланк одного стандартного шаблону.

Витягни значення заповнених полів і поверни **тільки JSON**, точно з цими ключами:

{
  // Шапка (кому адресовано) — стор. 1
  "addressee_org": "…",  // назва організації, кому адресовано заяву
  "addressee_person": "…",  // ПІБ особи, кому адресовано (у давальному відмінку)
  // Дані заявника з шапки — стор. 1
  "applicant_name_header": "…",  // ПІБ військовослужбовця в рядку «Від військовослужбовця» — як написано, разом обидва рядки
  "passport_series": "…",  // серія паспорта — літери у графі «Паспорт серія»; часто порожня, якщо заповнено ID
  "passport_number": "…",  // номер паспорта — цифри після «№» у тій самій графі; часто порожній, якщо заповнено ID
  "id_number": "…",  // номер ID-картки у графі «або ID»
  "passport_issued_by": "…",  // рядок «виданий» — усе, що там написано (дата видачі, номер), дослівно
  "tax_id": "…",  // РНОКПП (ІПН) — 10 цифр
  "military_rank_and_position": "…",  // військове звання / посада — весь рядок як написано
  "military_unit": "…",  // військова частина
  "phone": "…",  // телефон
  // Текст заяви — стор. 1
  "applicant_full_name": "…",  // ПІБ у рядку «Я, ...» — повністю
  "serviceman_status": "…",  // статус у рядку «є військовослужбовцем ...» (напр. ЗСУ, НГУ)
  "event_period": "…",  // період заходу — з якої по яку дату

  "spouse_full_name": "…",  // п.1 Дружина — ПІБ повністю
  "spouse_passport_series": "…",  // п.1 Дружина — серія паспорта
  "spouse_passport_number": "…",  // п.1 Дружина — номер паспорта
  "spouse_tax_id": "…",  // п.1 Дружина — ІПН
  "child_1_full_name": "…",  // п.2 Дитина — ПІБ повністю
  "child_1_birth_date": "…",  // п.2 Дитина — дата народження, як написано
  "child_1_certificate_series": "…",  // п.2 Дитина — серія свідоцтва про народження
  "child_1_certificate_number": "…",  // п.2 Дитина — номер свідоцтва про народження
  "child_2_full_name": "…",  // п.3 Дитина — ПІБ повністю
  "child_2_birth_date": "…",  // п.3 Дитина — дата народження, як написано
  "child_2_certificate_series": "…",  // п.3 Дитина — серія свідоцтва про народження
  "child_2_certificate_number": "…",  // п.3 Дитина — номер свідоцтва про народження
  "child_3_full_name": "…",  // п.4 Дитина — ПІБ повністю
  "child_3_birth_date": "…",  // п.4 Дитина — дата народження, як написано
  "child_3_certificate_series": "…",  // п.4 Дитина — серія свідоцтва про народження
  "child_3_certificate_number": "…",  // п.4 Дитина — номер свідоцтва про народження
  "member_5_full_name": "…",  // п.5 (вільний рядок) — ПІБ повністю
  "member_5_birth_date": "…",  // п.5 (вільний рядок) — дата народження

  // Службове
  "handwritten_notes": "…",  // рукописні позначки на полях, резолюції, дописки поза графами
  "unreadable_count": "…",  // скільки місць ти позначив як [?]

Правила:
1. Ключі не змінюй, не додавай свої, не прибирай. Порядок збережи.
2. Значення бери дослівно з документа. Не виправляй помилки, не розкривай скорочення, не переформульовуй.
3. Не вгадуй. Не читається символ або число — `"[?]"`. Не читається частина слова — `"Іва[?]енко"`.
4. Поле в бланку порожнє або цієї графи на цій сторінці нема — `"—"`.
5. Цифри переписуй по одній, обережно: у рукописному тексті плутаються 1/7, 3/8, 4/9, 6/0.
6. Жодного тексту поза JSON: без пояснень, без вступу, без ```-обгорток.
