# Презентація демо-дня: як вона зроблена

Готовий файл лежить поза git (він великий і не код):
`Desktop\Agentic AI\AI-секретар — Demo Day.html` — 298 КБ, **один файл**,
відкривається двічним клацанням, зовнішніх запитів нуль.

## Два файли тут

| Файл | Що це |
|---|---|
| `deck_body.html` | зміст і розкладка слайдів. Правити треба саме його |
| `build_deck.py` | вкладає шрифти в base64 і збирає готовий файл |

Перезібрати після правки:

    python docs/deck/build_deck.py

## Чому один файл, а не тека

Презентацію відкривають з флешки, з іншого ноутбука, з теки «Завантаження».
Файл, який тягне шрифт із сусідньої теки, у цих умовах ламається **молча**:
лишається системний шрифт, і вся розкладка з'їжджає. Один файл цього не вміє.

Вкладені лише латинські підмножини Plex — колода англійською, і кириличні
190 КБ нічого б не показали.

## Що взято з дизайн-системи Claude Design

`Desktop\Agentic AI\AI-секретар Design System-handoff\` — звідти шрифти
(IBM Plex Sans / Plex Mono), палітра (`#141a10` темна, `#fbfbfa` світла,
олива `#9fc47a` і `#46682f`), сітка на світлих слайдах і стиль надзаголовка
(`kicker`). Зміст слайдів наш.

Рішення Ані: усе до limitations на слайди не йде. Контекст проблеми дає Денис
до початку, далі живий показ, і лише потім колода.

1. Limits of what already works — шість речей, сказаних наперед
2. What we did not build in time — двома колонками: користувачу / оператору
3. Promised vs measured — шість обіцянок проти зміряного
4. Architecture — ланцюг і дві дороги відповіді
5. Q&A — опора: далі чотири слайди заготовлених відповідей
6. How we tested it — 31 знайдений дефект, золотий набір, незалежна перевірка
7. Protecting the data — «в місці» / «відкрите»
8. What needs a developer — день на форму, година на запит
9. Keeping the model in its lane — 48 атак і чому продукт тримається
