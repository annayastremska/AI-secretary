# Колода демо-дня

## Де живе зміст

Один слайд = один файл у `canvas/*.dc.html`. Порядок слайдів — `canvas/canvas.json`.
Правити треба **саме їх** (або сам слайд на канві — див. нижче), бо з них
збирається і канва, і файл для показу. Двох версій змісту не існує.

| Слайд | Про що |
|---|---|
| `Main` | титул |
| `Limitations` | що не доробили (1–5 з 9) |
| `NotYet` | що лишається відкритим (6–9 з 9) |
| `ByDesign` | що працює за побудовою |
| `Promised` | обіцяне проти зміряного |
| `Feedback` | фідбек продакт-овнера зі скріншотом |
| `TechArchitecture` | технічна схема (за проханням Андрія) |
| `ModelRules` | що моделі можна й чого ні |
| `QA` | питання |
| `Local` | один сервер (після QA — запас на питання) |
| `Risk` | де ризик (там само) |

`canvas-removed/` — слайди, прибрані з колоди, але не викинуті.

## Два виходи з одного джерела

**Канва** (правиться мишею, публікується як Artifact):

    node "<тека скіла design>/seed-canvas.mjs" \
      --template "<та сама тека>/payload.template.html" \
      --out canvas/ai-secretary-demo-day.html \
      --title "AI-Secretary Demo Day" \
      --artboard canvas/Main.dc.html ... --canvas canvas/canvas.json

**Один HTML-файл для показу** (відкривається двічним клацанням, стрілки
гортають, `Ctrl+P` дає PDF):

    python docs/deck/build_html.py

## Три речі, які тут зроблені навмисно

**Шрифти вкладені в base64, посилання на Google Fonts вирізане.** Файл
відкривають із флешки й із чужого ноутбука, а збій із зовнішнім шрифтом
МОВЧАЗНИЙ: лишається системний шрифт, і розкладка з'їжджає.

**CSS кожного слайда прив'язаний до свого слайда.** На канві кожен артборд у
власному iframe, тому однакові класи не бачать одне одного. В одному файлі
вони опинились би в спільній голові й тихо перебивали одне одного.

**Ненайдена картинка — падіння збірки, не попередження.** У браузері вона дає
просто порожню рамку, тобто збій, який видно лише оком і лише на показі.
