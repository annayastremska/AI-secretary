What the unit should know first.

documents, not peopleThe system knows what is written down. If someone came back early and no one wrote it, it does not know.
one person, two placesRefused when the system creates a document. Accepted when it receives one — two such pairs sit in the database now.
lawful or not, same lookA replacement slip says “instead of №118”. We read that line and do not store it, so we cannot tell a replacement from a contradiction.
nothing closes the queue31 documents wait for a person. There is no screen to confirm them, and no way to close a remark.
All four are visible on the live system right now.
