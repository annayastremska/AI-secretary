Everything on one server
The model runs here. 27 billion parameters, on our own graphics card. No API, no external service, nothing to pay per question.
The database is here. Documents, facts, regulations — all on the same machine.
The pages call nobody. Even the fonts are local, so no outside service learns that someone opened the chat.
The price is the hardware. Without a real GPU the same work takes tens of seconds instead of tenths.

one machine with a GPU
no internet connection
