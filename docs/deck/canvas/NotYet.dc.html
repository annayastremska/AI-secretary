The document-creation feature fills forms. It cannot add a new kind of query — that is still a file we edit by hand.

Our own numbers say the chat can do better.
Across 127 test questions the rules take 82 and get 61 right. The rest go to the model. We measure this on purpose — it is where the next work is.

27 billion parameters on our own GPU. Nothing leaves the network — and nothing works quickly without that card.
