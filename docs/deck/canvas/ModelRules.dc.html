What the model may do
It is a translator between a question and a list of ready queries. Nothing more was allowed.
Allowed
Choose and extract
✓pick one query from a written list of 31
✓pull the date, the surname, the unit, the document number out of the question
✓say whether a found clause actually answers the question
✓write a query itself — only when no ready one fits, and only a single read
Never
Speak for the system
✗write the sentence you read — that is assembled by code from database rows
✗see the database, or the results of any query
✗invent a missing parameter — an empty field stays empty
✗change, delete or add anything: its access is read-only three times over
What it is given
A short memory
›the question, and the one turn before it
›six things carried over: what was asked about, the date, the unit, the person, the document, the place
›the list of queries — read from the same file that runs them
›today's date, from the code. It is never asked to know what day it is
Anything carried over from the previous turn is said out loud in the answer — a silent guess is an answer to a different question.
