Three blocks
READ IT · STORE IT · ANSWER FROM IT
01 · READING
Three ways in
●Word — text straight from the file
●PDF — text layer first, pixels if none
●photo — read on our own card
Then one path: recognise the form, pull the fields.
02 · THE DATABASE
Two kinds of content
●Facts — who, what, when, and which document says so
●Regulations — full text, cut into clauses with addresses
●plus the people register and what a human must check
Every fact keeps its source and its state.
03 · THE CHAT
Two ways out
●A number — one of 31 ready queries
●A quote — found, then matched word for word
●or “no data”, with the reason
The model picks a query. It never writes the answer.
