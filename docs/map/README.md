# Мапа двох доріг

`roads-map.excalidraw` — жива схема архітектури: як питання проходить від входу
до відповіді кожною з двох доріг.

## Як відкрити

Перетягнути файл у [excalidraw.com](https://excalidraw.com) — редагується прямо в браузері,
нічого встановлювати не треба.

## Чому не PNG

Excalidraw-файл редагується, картинка — ні. Схема змінюється щотижня, тому
джерелом лишається `.excalidraw`.

**Треба зробити:** експорт у `.svg` поруч із файлом — GitHub рендерить SVG
при відкритті, і схему буде видно без завантаження. Робиться з excalidraw:
Export → SVG.
